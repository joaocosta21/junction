A gateway that lets a buyer's purchasing agent read Valio Aimo's prices and availability, get an offer and order within its authority or with human approval. The same functions are open as REST and as MCP tools: OpenAPI document · JSON Schemas · health.

Buyer profiles, spend limits and approver names on these pages are illustrative: they are ours, chosen for the demonstration. An order here is a record in your own demo order book, which the REST API and MCP do not share; the Valio Aimo mock has no order endpoint, so it commits nobody.
