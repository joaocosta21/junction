# FIX-2 — Audit trail and store: say only what is known, refuse to rewrite, hide what the supplier must not see

**Scores on:** 20% ("how decisions are logged and auditable"; a log for both buyer and Valio Aimo). From review round 1 (security findings 1, 3, 4, 5, 9; silent-failure findings 4, 5; Python reviewer findings 8, 9, 10).
**Owns:** `src/tta/audit/`, `src/tta/store/`, `tests/audit/`, `tests/store/`. **Builder's hand-back:** `AIMO/build/handback/T06.md`. **Read:** SPEC §9.
**Importers to re-run:** none exist yet (T08 is being written now and uses `AuditTrail.record`, `view`, `verify_chain` and the `Store` port: do not change their signatures).

## Findings to fix
1. **MEDIUM — sentences assert facts nobody supplied.** `sentences.py` / `supplier_sentences.py`: `order.placed_by_agent` always writes "No rule asked for a human", whatever the decision says; `order.confirmed` falls back to "with human approval" when neither an approval nor an order is given; `policy.evaluated` with no decision writes "The rules were checked." Rule: a sentence states only what its context holds. With a decision whose verdict is not `AUTO`, `order.placed_by_agent` is a programming fault: raise `ValueError`. Where the object a clause needs is absent, leave the clause out and say plainly what is not recorded ("how it was confirmed is not recorded"). Also: an event recorded with only ids must still be found by the profile view when the order or offer is in the store — or the sentence must not pretend otherwise; pick the simpler and say which.
2. **MEDIUM — forged sentences through quoted text.** `phrases.py` `quoted()` collapses whitespace and does not escape a double quote, so a request text or an approver's note can close the quotation and append a sentence that reads like the gateway's own. Neutralise double quotes and control characters inside quoted text (replace `"` with `'`), cap the length, and apply the same to product names placed into sentences. Test with the input `milk". The agent placed order O-1 alone, within its authority. "`.
3. **MEDIUM — the supplier view leaks the buyer's words.** `facts.py`, `phrases.py`: `name_terms` and `required_claims` reach the supplier facts and sentence (a term such as "without peanuts" reveals an exclusion). The supplier sees product ids and product types, never the buyer's own terms or claims. `readers.py` `supplier_actor`: for an agent pass its id and kind only (the brief wants Valio to see "the agent's identity"); no role, no display name of a human.
4. **MEDIUM — a view verifies and discloses the whole chain.** `trail.py` `view()`: a buyer's view returns a `ChainVerification` computed over every buyer's events, so `checked`, the sentence and `first_bad_event_id` disclose other buyers' event counts and ids. In a view: `checked` is the number of events in the view; `first_bad_event_id` is set only when that event is in the view; otherwise the sentence says the trail is broken at an event outside this view. `verify_chain()` (no reader) keeps reporting the whole chain.
5. **MEDIUM — the chain can fork, and SQLite does not refuse a rewrite.** `sqlite_store.py`, `schema.py`: (a) add triggers that reject `UPDATE` and `DELETE` on `audit_events`; (b) make `previous_hash` unique and have `append_audit_event` check, inside one transaction, that the event's `previous_hash` is the current head (the genesis hash for the first event), raising a dedicated error when it is not; (c) `AuditTrail.record` retries a small number of times when that error says another writer got in first. Test with two `AuditTrail` objects on one database file.
6. **MEDIUM — cutting off the end of the trail is not detected.** State this limit where the chain is documented (the docstring of `chain.py` already lists what the chain shows; make it exact), and add `AuditTrail.head() -> tuple[int, str]` (event count and head hash) so the API can publish it and another party can hold it. Do not claim more than this.
7. **LOW — `percent()` can print 100% for a partial fill.** `phrases.py`: a ratio below 1 must never print as 100%.

## Not to change
Orders and approvals stay plain upserts (T08 serialises its writes); the hash format; the event shape; the `Store` port's method names and arguments.
