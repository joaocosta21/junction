## Assumptions
- The product-type table is ours: 29 keys, categories inferred from the English names in each category, counts over the whole catalog.
- `milk` is the whole of category 10400 (91 products), which also holds a sour milk, a coffee drink and a soy yoghurt. Lactose-free milk is `milk` plus claim `FREE_FROM_LACTOSE`: exactly 35.
- `plant_drink` is category 10402 narrowed by name terms to 51 of 66: it leaves out 13 coconut milks for cooking, 2 iced coffees and 1 oat cooking base. `chicken`, `flour`, `french_fries` and `beef_chuck` are narrowed the same way.
- **Name terms, changed from the SPEC's wording:** a term matches when it is in the English name or the Finnish name; English matches are listed first. "Finnish only when English finds nothing" fails on the data: "maito" starts a word in 2 English names (both chocolate bars) and is in 233 Finnish names.
- English names match at the start of a word ("tea" does not find "steak"; "steak" does not find "Flanksteak"). Finnish names match anywhere; a term under 4 letters must start a word.
- Fallback without a product type: keep the largest category and every category with at least half as many matches. Applied only when there are name terms and no product type, ids or category prefix.
- Pack size from the price: a comparison price is exact to half a cent. When the product file's own figure fits the two prices, that figure is returned with source `PRICE_RATIO` (10 litres, not 9.943); otherwise the ratio to 3 decimals.
- A product whose sales unit is `KG` is 1 kg per sales unit. A weight is never turned into litres or the other way round.
- A conversion row is used only when it can be tied to a unit: by GTIN for a base row (Sofia's rule), as the case when the sales unit holds more than one base unit; pallet rows are not used.
- A size in a name counts only when the name has exactly one size, or one "N x M" pattern that agrees with the units per sales unit. English name, else Finnish.
- Portion pack: a sales unit holding more than one inner unit of 5 cl or 50 g or less, read from the product file alone. Inner size unknown → not a portion pack. 744 products qualify (catalog).
- Lot: `allowedLotSize` 0.01 means no step set. Countable sales units are ordered whole (16,476 products); products sold by the kilogram keep 0.01 kg (396); the 674 real steps are used as given.
- `countryOfOrigin` values `zy`, `xs`, `zz` (195 products) are not an origin and load as `None`; real codes are stored in capitals.
- `has_allergen_groups` is true when the file carries the `allergen` or `nonAllergen` group, even empty; it is false on 11 products.
- `listed_substitutes()` returns Valio's pairs as listed, one direction, without the product itself (`471661` lists itself). `Product.listed_substitutes` keeps the file's 250 pairs.
- `from_settings` needs all three files; a missing or malformed one stops the start-up rather than serving a partial catalog.
- A search with no filter, or an unknown product type, is `invalid-request`. An unknown id in a search is named in `note`; raising `unknown-product` is left to the caller, using `get_product`.
- Data facts found on the way: `476872` has a unit row (`ZML`) of size 0.0; `472492` (lactose-free sour milk, 5 kg) is priced per kg and has no volume, so its pack size in litres is unknown and it will drop out of a litre request with `PACK_SIZE_UNKNOWN`.

## Contract changes needed
- `PackSizeSource`: add `SALES_UNIT`. A product sold by the kilogram is 1 kg by definition; without a price it is reported as `UNIT_CONVERSION` today.
- `errors.py`: a typed error for an unusable data file. The catalog raises `SupplierUnavailable` (503) today.
- `Catalog.pack_size`: add the sales unit of the API line. The API prices another unit than the file on 7 of 797 lines (FINDINGS §1); the price ratio handles that, but with no comparison price the figure is per file sales unit. Until then T07 should treat a pack size whose source is not `PRICE_RATIO` as unknown when the two units differ.
- `SearchResult`: an `unknown_ids` field would be cleaner than naming them in `note`.
