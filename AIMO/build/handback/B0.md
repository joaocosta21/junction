## The decision: P-00 is retired; F-10 is the rule the setting drives, and it stays in code
- **P-00 is deleted from `rules.yaml`.** It fired next to every other rule, so it could not stay beside F-10. All 34 F-10 pins of Sofia's commit hold unchanged.
- **F-10** (`src/tta/policy/human_approval.py`) reads `profile.auto_order_enabled`. Off: an order no other rule sends to a person goes to the purchasing manager. On: the agent orders alone only when no rule fires **and every statement of every line is confirmed** (price, quantity, delivery date, allergens, origin). One unknown or missing statement and F-10 still fires, naming it. This is the runbook's "only when every statement is confirmed", taken literally: no rule of the file reads the origin statement, and the allergen statement only against an exclusion.
- F-10 is **no longer marked fixed** (a setting switches it), so it left "Always, whatever you set" and is listed after the fixed rules, before P-01.

Not moved to data: it fires only when nothing else asks for a person, which a `when` cannot say; it would need a new trigger kind. ## Assumptions and defaults taken
- "Every statement confirmed" means all five statements present and `CONFIRMED` on every line. So with the setting on, a request with no needed-by date (delivery date `UNKNOWN`) still goes to a person.
- A demo clock outside dev and demo stops the start; in live mode it is ignored, logged, and `/healthz` says "not honoured". The "as of" clock for live mode (P5 C5) is not built.
- A renewal whose order cannot be found still counts (unchanged: leaving it out could only remove a check).
- The type note shows on every line that asks for `milk`, lactose-free or not.
- The coffee-milk terms are "coffee milk", "kahvimaito", "cafè milk" (not "cafè": a sentence about a café must not name the type; checked with one sentence).
- The three customer values the runbook decided (school `STRICT`, bakery no substitute alone, ward drift 0.1) were **not** written into `kitchens.js`: the six steps do not name them and `UI-CONTRACT.md` gives them to Gabriela (F5).
