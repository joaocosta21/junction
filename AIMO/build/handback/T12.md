## Assumptions
- Scenario 3 is a request that names `473609` ("100 litres of Oddlygood Barista oat drink, product 473609, by Monday"), asked by the hotel kitchen agent. The result lists the ranked substitutes of each product id the request names (3 at most).
- The examples are the three scenarios of PLAN §3. The backup (30 kg beef chuck) has no button.
- Who reads the text, in order: the buyer agent when there is one; else the parser; else, for an example only, its typed request. The typed request is used only when the model is unreachable, cannot read the sentence, or is rate-limited.
- After the agent was asked about an example and failed, the parser is not asked again.
- For free text, an agent whose model is unreachable hands over to the parser; any other refusal is shown as it is.
- The page orders the offer's top option (`options[0]`) with the key `page-<24 hex>`. A form key runs once: a double submit, a reload or a re-sent form orders nothing more.
- The page keeps the last 200 runs in memory, for "how it was read" and the agent's steps. After a restart a result shows the offer, the order and the outcome only.
- An offer or an order is read as each demo agent in turn, the chosen one first. Another buyer's id is `not-found`.
- The supplier view is built only from the supplier's view of the audit trail (the `order` fact of its newest event, validated). The page redacts nothing itself.
- The `/healthz` audit head is shown by the static script, because the service has no head function. Without the script the page links to `/healthz`.
- The CSRF token is a double-submit cookie with no server state, so it survives restarts and more than one process. The chosen agent and approver are cookies (`tta_agent`, `tta_approver`).
- CSP: `default-src 'none'`; `'self'` for script, style, img and connect; `form-action 'self'`; `base-uri 'none'`; `frame-ancestors 'none'`. Pages also send `Cache-Control: no-store`.
- `docs/ASSUMPTIONS.md` is rendered by the package's own escaping Markdown renderer (512 KiB at most; only http(s) links become links).
- The first five exclusions shown cover each reason once before repeating one. The summary's "Confirmed" holds the options whose every line is `confirmed_for_order`.
- Times are shown in the offset they were stated in (Valio: +02:00). The audit timeline shows its own event times in UTC.
